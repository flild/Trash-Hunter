# После закрытия I-010–I-040

Техническая приёмка завершена, эстафета закрыта. Итоговый локальный Windows x64
Player находится в `Builds/I-040/TrashHunterPrototype.exe`. Запускать из папки
сборки. Управление и ожидаемый результат описаны в [отчёте I-040](sessions/2026-11-25-i040-windows-playtest.md).

Владелец решает, провести ли плейтест по [протоколу](design/PROTOTYPE.md#протокол-плейтеста--предложение)
или принять технический результат с текущим ограничением: наблюдений за
игроками 0. Пороги записи и загрузки C-111 ждут решения по
[замерам I-030](sessions/2026-11-25-i030-expedition-save.md#замеры-для-c-111).
I-050 требует отдельного решения владельца.
