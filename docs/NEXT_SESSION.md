# Следующая сессия · I-230

Выполнить I-230 — след исчезнувшего дома. Начать с [передачи](relay/chapter-one/HANDOFF.md), [плана](relay/chapter-one/PLAN.md), [контекста](relay/chapter-one/CONTEXT.md) и строки I-230 в [очереди](BACKLOG.md#первая-игровая-глава).

После первой продажи на подходящей вылазке становится доступна домашняя метка. Осмотр обеих сторон даёт адрес и номер партии. По этим сведениям старьёвщик направляет игрока в другой двор с отдельным подходом, укладкой и добычей. Там находится повреждённый прибор с тем же номером. Пропуск метки и восстановление из автослота проверять по [правилам вещдоков](design/STORY.md#вещдоки-и-доступ-к-сведениям). Итог главы — обнаружение прибора и продолжение во втором дворе.
