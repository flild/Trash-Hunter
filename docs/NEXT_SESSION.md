# Следующая сессия — I-120

Выполнить завершающий этап эстафеты поиска. Собрать Windows x64 Player
в отдельной от I-040 папке. В Player пройти прыжок, извлечь шкаф,
открыть упаковку, бросить вещь, переставить содержимое сумки при занятой
руке и уложить находку. Проверить продажу, новую вылазку и продолжение
после закрытия игры. Повторить затронутый интерфейс в RU/EN.

Начать с [передачи I-120](relay/search/HANDOFF.md). Сверить критерии в
[плане](relay/search/PLAN.md). Сохранить путь к exe, управление, лицензии,
показатели кадра и конкретный остаток ручной проверки. Для сравнения
использовать сценарии из [отчёта I-110](sessions/2026-11-27-i110-pile-look.md).
