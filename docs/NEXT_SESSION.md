# Следующая сессия — I-150

По команде продолжения выполнить I-150 по [передаче](relay/world/HANDOFF.md).
Координатор должен сопоставить ID локации со сценой и точкой входа и
провести асинхронный переход от команды до готовности управления. Начать
с текущего `SearchSession.Reload` и результата загрузки в `GameState.Location`.
Условия обработки отказов и проверки на двух сценах описаны в [плане](relay/world/PLAN.md).
