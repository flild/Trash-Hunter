# I-240 — исходная глава в Windows Player

Декабрьская эстафета готова. Взять один этап по [текущей передаче](relay/HANDOFF.md). Критерий I-240 и статус вести в [бэклоге](BACKLOG.md#декабрь-2026).

Сверить Git status и [инструкции проекта](../AGENTS.md). Прочитать [DEVELOPMENT](DEVELOPMENT.md) и [отчёт I-230](sessions/2026-11-28-i230-chapter-evidence.md). Сопоставить игровой маршрут [VerifyChapterEvidence](../AgentScripts/Verification/VerifyChapterEvidence.cs), подготовка которого использует UnityEditor, со способом запуска [проверки Windows Player](../AgentScripts/Verification/VerifySearchPlayer.cs).

Собрать текущую главу в отдельный локальный каталог. На RU и изолированном слоте получить наводку старьёвщика, перейти во второй двор, осмотреть кассетник и выйти. Запустить новый процесс с тем же слотом. Сверить двор, сюжетный факт и экземпляры вещей. Сохранить три прежних комплекта Builds и пользовательский слот.

В отчёте указать версию, команды и результат повторного запуска. При сбое сохранить точку воспроизведения и путь к слоту. После приёмки обновить статус и передать I-250. При незавершённом результате передать остаток I-240.
