По команде начать разработку прочитать AGENTS.md, [DEVELOPMENT](DEVELOPMENT.md), [отчёт I-230](sessions/2026-11-28-i230-chapter-evidence.md) и проверить текущий Git status. Для отдельного процесса адаптировать игровой проход по образцу [проверки Windows Player](../AgentScripts/Verification/VerifySearchPlayer.cs). Рабочая локаль RU. Сохранить три прежних комплекта Builds и пользовательский слот.

Собрать отдельный локальный Windows Player для текущей главы. В изолированном каталоге пройти от встречи с меткой через разговор во второй двор, осмотреть кассетник и выйти. Запустить новый процесс Player с тем же каталогом. Сверить двор, сюжетный факт и экземпляры вещей. Записать версию, способ запуска, результат и при сбое точный шаг и путь к воспроизводимому слоту. После успешного прогона обновить статус I-240. Следующая независимая задача — I-250, описание тем разговора.
