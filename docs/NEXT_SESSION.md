# Следующая сессия — I-160

По команде продолжения выполнить I-160 по [передаче](relay/world/HANDOFF.md).
Сверить Git и [карту папок и сцен](DEVELOPMENT.md#структура-проекта).
Начать с владельцев домашнего запаса, предложения продажи и поиска в
`Runtime/Run/GameState.cs` и `Runtime/Search/SearchSession.cs` внутри
`Assets/TrashHunter/`.
Подключить отдельную сцену старьёвщика, входы и выходы через координатор.
Проверить маршрут поиск → дом → старьёвщик → дом → новая вылазка,
однократность продажи и продолжение из каждой зоны.
[Границы и критерии](relay/world/PLAN.md).
