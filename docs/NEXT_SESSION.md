# Следующая сессия — ручная приёмка поиска

Эстафета I-060–I-120 закрыта. Для ручной проверки использовать локальный
Windows x64 Release `Builds/I-120/TrashHunterPile.exe` и отдельный
каталог автослота. Маршрут и управление описаны в
[отчёте I-120](sessions/2026-11-27-i120-windows-acceptance.md#управление-и-ручная-проверка).

При проверке физической клавиатурой и мышью оценить извлечение шкафа,
читаемость подсказок и выбор добычи. Ожидается, что игрок сможет выбраться
из контейнера, уложить находку после перестановки вещей с занятой рукой
и продолжить вторую вылазку с прежней позицией и содержимым. Замеры
[C-104](ROADMAP.md#целевые-параметры) остаются открытыми до проверки
на референсном ПК. I-050 указан в [BACKLOG](BACKLOG.md#эстафета-прототипа)
как отдельная задача по решению владельца.
