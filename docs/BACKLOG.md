# Задачи и план эстафеты

Цель: согласованный проект полноценной игры для Steam и документальная база,
по которой Codex сможет выполнять ограниченные задачи без выдумывания правил.
Сейчас только документация; реализация требует отдельного прямого указания.

Это единственная очередь. Статусы: `todo / in_progress / done / blocked`.
P0/P1 обозначают приоритет, не срок. `done` у документа не означает, что интерес
или производительность игры уже доказаны. Порядок строк — порядок обсуждения;
старые ID сохранены. Источники: [DECISIONS](DECISIONS.md), актуальные документы
из [карты](README.md), [ревизия A-01–A-12](design/DESIGN_REVIEW.md).

Следующая задача — **D-010 — причинный каркас сюжета и характер ужаса** (`todo`).

Для каждой темы обсуждать по 2–3 связанных вопроса. Нерешённый этап остаётся
`in_progress`; частичный ответ не превращает весь раздел в утверждённый.
Предложения агента не становятся требованиями без ответа владельца.

На D-006 достаточно определить направление и ограничения. Точные числа,
длительность, стоимость производства и минимальная машина не подставляются
автоматически: они уточняются в профильных этапах и D-075.

Готовность D-080 означает готовность документации, не разрешение писать код.
Будущий прототип может опровергнуть гипотезу; тогда соответствующее правило
пересматривается вместе с владельцем, а не маскируется дополнительными системами.

## Оформление и завершение эстафеты

23.11.2026 существующая эстафета оформлена через `relay-lifecycle` по просьбе
владельца, без выполнения этапа. Присланный промпт D-020 устарел: по документам
он уже `done`; на момент оформления следующей задачей была D-030. ID,
зависимости, критерии и продуктовые статусы при оформлении не изменялись.

Эта эстафета охватывает проектирование D-* до D-080. После готовности всех
этапов предложить владельцу закрытие через `relay-lifecycle`; автоматической
уборки нет. Учёт файлов — [relay/FILES](relay/FILES.md). Выполнение I-* требует
отдельного прямого разрешения и не запускается после D-080 автоматически.

## Уточнение очереди 22 ноября

Прежняя следующая задача D-010 уступила ревизии по новому запросу владельца.
Добавлены D-005, D-006 и D-075; остальные ID не перенумерованы. Конкретные
записи CONCEPT о перевозке, тирах, убежище и достижениях нельзя считать
исключёнными по старой таблице: это пожелания владельца, их конкретные правила
согласуются начиная с D-006.

По прежним решениям мультиплеер, открытый город и сложная жизнь жителей
исключены из базового объёма. Желание развивать продукт после выпуска само
по себе не разрешает live-service, серверы, DLC, сезонную систему или дополнительную монетизацию.
