# Задачи

Статусы: done — выполнено; next — следующая задача; planned — запланировано;
gated — исполнение ждёт решения/предыдущего этапа. P0 важнее P1; это приоритет,
не срок. Документы ниже содержат черновики, не готовые утверждённые системы.

## Проектирование

| ID | Приоритет / статус | Задача | Критерии готовности |
|---|---|---|---|
| D-000 | P0 / done | Создать письменный фундамент и правила эстафеты | Карта, состояние, решения, дизайн, архитектура, план проверки и NEXT_SESSION существуют; нет игрового кода |
| D-010 | P0 / next | Согласовать основу сюжета и степень хоррора | Выбраны тайна, цель героя, финальный поступок и тон; есть причинная цепь завязка→развязка, роли контактов, правило обязательных улик; предложения отделены от решений |
| D-020 | P0 / planned | Зафиксировать вылазку и взаимодействие | На примерах решены начало/конец, промежуточная разгрузка, рука/сумка, выход из игры/провал, вход в контейнер и режим осмотра |
| D-030 | P0 / planned | Описать предметы и переноску | Выбран формат вместимости; состояния/признаки; правила крупной вещи и сюжетного следа; пример минимум двух разумных выборов |
| D-040 | P1 / planned | Согласовать еду, воду и эффекты | Определены расход, признаки, употребление, провал, отравление/рвота, галлюцинации, ускорение, пауза и доступность; нет обязательного отравления ради сюжета |
| D-050 | P0 / planned | Спроектировать развитие и бумажную экономику | Есть цель бизнеса, последовательность контактов/навыков, одна модель ремонта, тестовый набор цен/объёмов, способ продолжить без денег |
| D-060 | P1 / planned | Согласовать арт/звук/UX и подобрать коллекции | Есть референсы, основные экраны/действия, правила читаемости/комфорта; небольшой список бесплатных наборов с проверенными условиями, затем их легенды |
| D-070 | P0 / planned | Уточнить архитектуру по согласованным правилам | Выбраны UI и подход игрока, владельцы данных и границы, политика сохранений; инварианты покрывают сценарии D-020–D-050; нет лишней инфраструктуры |
| D-080 | P0 / gated | Проверить дизайн и выбрать первую реализацию | Нет блокирующих противоречий; объём/ограничения и критерии первой задачи согласованы; владелец прямо разрешил код |

D-010 не требует за один чат написать все диалоги. Если владелец ещё выбирает
основу, продолжить D-010, зафиксировать частичный результат и следующий вопрос.
D-020–D-070 уточняются по выбранной концепции; новые идеи не расширяют объём молча.

На D-080 отдельно решить, что действительно нужно знать до прототипа, а что
останется проверяемой гипотезой: количество контента, длительность, минимальный
ПК, языки/контроллер, бюджет. Не обещать финальную стоимость без этих данных.

## Реализация — сейчас закрыта

| ID | Приоритет / статус | После чего | Результат и проверка |
|---|---|---|---|
| I-010 | P0 / gated | D-080 и прямое разрешение | Отдельная сцена, доступный контейнер, малый физический набор, перемещение и осмотр; проверка в Editor и руками владельца |
| I-020 | P0 / gated | I-010 | Ограниченная переноска, безопасный возврат/выброс; проверка вместимости и уникальности |
| I-030 | P0 / gated | I-020 | Устойчивая вылазка и продажа; граница не обновляет добычу, повторное подтверждение не даёт денег |
| I-040 | P0 / gated | I-030 | Плейтест по PROTOTYPE, записаны наблюдения и решение продолжить/переделать |
| I-050 | P1 / gated | Успешный I-040 | Спланировать малый вертикальный срез по ROADMAP; не реализовывать все поздние системы одной задачей |

## Отложено до решения

Обустройство помещения находками (Q-010), полная поздняя оценка ценного лута
(Q-006), финальное число концовок, контроллер, Steam Cloud и достижения.
Мультиплеер, открытый город и сложная жизнь жителей исключены из базового объёма,
а не просто ожидают очереди в этой таблице.
