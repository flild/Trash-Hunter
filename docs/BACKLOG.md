# Задачи и план эстафеты

Цель: согласованный проект полноценной игры для Steam и документальная база,
по которой Codex сможет выполнять ограниченные задачи без выдумывания правил.
Сейчас только документация; реализация требует отдельного прямого указания.

Это единственная очередь. Статусы: `todo / in_progress / done / blocked`.
P0/P1 обозначают приоритет, не срок. `done` у документа не означает, что интерес
или производительность игры уже доказаны. Порядок строк — порядок обсуждения;
старые ID сохранены. Источники: [DECISIONS](DECISIONS.md), актуальные документы
из [карты](README.md), [ревизия A-01–A-12](design/DESIGN_REVIEW.md).

Для каждой темы обсуждать по 2–3 связанных вопроса. Нерешённый этап остаётся
`in_progress`; частичный ответ не превращает весь раздел в утверждённый.
Предложения агента не становятся требованиями без ответа владельца.

На D-006 достаточно определить направление и ограничения. Длительность и референсный ПК закреплены как ориентиры в D-075. Точный
баланс и стоимость производства уточняются по будущим замерам и пробной партии.

Готовность D-080 означает готовность документации, не разрешение писать код.
Проверка в рабочем срезе может опровергнуть гипотезу. В этом случае правило
пересматривается вместе с владельцем.

### Захват предмета из-под ног (I-080)

- **Воспроизведение.** Встать на подвижный предмет, навести на него прицел
  и взять ЛКМ. Предмет тянется вверх и поднимает стоящего на нём персонажа.
- **Критерий готовности.** При попытке захвата персонаж остаётся на устойчивой
  опоре либо падает под действием гравитации. Проверить захват того же
  предмета с пола и прыжок с устойчивой опоры.

## Отложенные задачи

### I-130. Перетаскивание в инвентаре и ячейки рук

Статус `todo`. Отдельная задача для будущей переделки инвентаря.

- В сетке сумки игрок зажимает кнопку мыши на предмете, тянет его и
  отпускает в нужной ячейке. При недопустимом размещении или отмене предмет
  остаётся на исходном месте.
- В интерфейсе есть отдельные ячейки рук, которые показывают, что персонаж
  держит. Игрок может перетащить вещь из сумки в ячейку руки, чтобы взять
  её, и из ячейки руки в сумку, чтобы уложить предмет.
