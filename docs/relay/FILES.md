# Учёт файлов эстафеты прототипа

Корень — `F:\UnityProjects\Trash-Hunter`. Объём — I-010–I-040. Режим уборки — по команде владельца «заверши эстафету». При подготовке запрошен только старт эстафеты.

## Сохраняемые документы

До подготовки существовали `docs/relay/PLAN.md`, `docs/relay/CONTEXT.md`, `docs/relay/HANDOFF.md`, `docs/NEXT_SESSION.md`, `docs/BACKLOG.md`, `docs/PROJECT_STATE.md`, `docs/README.md` и `docs/design/PROTOTYPE.md`. Они используются для работы и сохраняются при закрытии. Постоянный отчёт этой подготовки — `docs/sessions/2026-11-24-prototype-relay.md`.

Перед уборкой сохранить решения, результаты проверок и путь к локальному Player в состоянии проекта и постоянном отчёте. Обновить указатели передачи и проверить ссылки. Новые временные файлы регистрировать только по проверенным точным путям.

Локальная итоговая сборка `Builds/I-040/` — результат этапа. При уборке
сохранить исполняемый файл, данные, библиотеки и уведомление о лицензии.
