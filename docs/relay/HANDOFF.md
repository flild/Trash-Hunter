# Текущая передача

Единственная актуальная передача — [docs/NEXT_SESSION.md](../NEXT_SESSION.md).
Там завершённый этап, следующий ID, проверенное состояние Git, проверки,
незавершённое, вопросы владельцу и первое действие.

План — [BACKLOG](../BACKLOG.md), контекст — [PROJECT_STATE](../PROJECT_STATE.md).
Не создавать параллельную передачу и не продолжать по устаревшему ID из чата.

Результат закрытого этапа, состояние Git, следующий ID и входные условия
собраны в актуальной передаче. При продолжении использовать `relay`.
Учёт файлов и режим закрытия — [FILES](FILES.md). Автоматическая уборка
не разрешена; обычная передача этапа не закрывает эстафету.
