# Контекст первой игровой главы

28 ноября владелец выбрал недельный план для разработки с нейросетями. Каждый чат берёт игровой этап целиком, включая нужные ему код, контент, интерфейс и проверку в Unity. Организованный плейтест и отдельные задачи для QA или тимлида в очередь не входят.

В I-190 уже есть поиск, убежище, старьёвщик, автослот и поручение РП-07 с открытием контакта мастера. Реализуем работу мастера поверх этого контакта. ## Договорённости между этапами

- Один и тот же экземпляр проходит путь от упаковки до продажи. ID, собственник или местонахождение, грязь, неисправность, выполненная работа и раскрытые сведения переживают переход и загрузку по мере реализации соответствующей механики. Повтор сделки или вскрытия не создаёт ещё одну вещь.
- При выполнении I-200 владелец отдельно подтвердил атомарную запись вскрытия и замену списка физическим выпадением. Отказ записи оставляет прежнюю принадлежность вещей. Совместимость проверена на копии старого слота с вилкой в руке и моторчиком в мешке. [Приёмка](../../sessions/2026-11-28-i200-physical-search.md).
- Выбранная 28 ноября схема работы в мире — зажать ЛКМ для переноса, отпустить для падения, нажать ПКМ для броска. В осмотре и в открытой сетке ввод принадлежит соответствующему экрану. При переходе между ними вещь остаётся доступной. Для новых подсказок нужны RU и EN.
- Визуальное наполнение кучи сохраняет доступ к находкам и оставляет место для физического падения содержимого. Предложенные эффекты запаха и брызг, изменения правил тиров и финальные цены остаются открытыми. Они не блокируют I-200.
- При выборе контента использовать существующие модели и источники по [правилам проекта](../../../AGENTS.md). Взаимодействие со столом, мастером, прилавком и уликой происходит через предмет в мире. Окна нужны для сравнения, цены и действий, которые требуют уточнения.

Корень — `F:\UnityProjects\Trash-Hunter`, PowerShell. Схемы Unity CLI/Pipeline, проверки в Editor и правила работы с ассетами — в [DEVELOPMENT](../../DEVELOPMENT.md). Каждый исполнитель проходит свой игровой эпизод и записывает, что увидел. Сводный маршрут завершает I-230.
