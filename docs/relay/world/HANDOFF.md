## Результат I-140

`RunBootstrap` поднимает области приложения и прохождения и читает автослот
до Awake первой сцены. `GameState.Location` берёт начальную зону из `atHome`.
Каталог живёт в `Assets/TrashHunter/Resources/LootCatalog.json`. ContainerSearch
подключается к существующему состоянию и генерирует первую укладку для
пустого слота. Дом пока показывается текущим экраном SearchSession.

В Unity Editor `script eval --file AgentScripts/VerifyRunStartup.cs` прошёл
16 проверок для каждого из трёх старых слотов и 7 для новой игры. У старых
файлов сверены данные и байты до и после подключения ContainerSearch.
`VerifyLootPackages.cs` прошёл 37, 39 и 5 проверок на старте, продолжении и
отправлении из старой вылазки. Свежая компиляция успешна, в консоли Editor
0 ошибок и предупреждений. Editor оставлен в ContainerSearch вне Play Mode.
Ручной прогон и запуск нового Windows Player остались вне проверки.
[Слоты, команды и результаты](../../sessions/2026-11-27-i140-run-startup.md).
