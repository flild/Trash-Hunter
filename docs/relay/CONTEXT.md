## Основание оформления

Источник: прямой запрос владельца 23.11.2026 — привести уже начатую эстафету
к `relay-lifecycle`, досоздать нужные документы, сам этап не выполнять.
Приложенный владельцем промпт D-020 устарел относительно файлов: BACKLOG,
DECISIONS и отчёт D-020 согласованно фиксируют его завершение. Актуальная
передача сохранена без отката решений; новые продуктовые решения не принимались.

Существующие PLAN / CONTEXT / HANDOFF остаются указателями на основные
документы. Они не объявляются временными задним числом. Учёт новых
вспомогательных файлов и закрытие по команде владельца — [FILES](FILES.md).
