# Контекст декабрьской эстафеты

Корень Git и Unity — `F:\UnityProjects\Trash-Hunter`, Windows PowerShell. При подготовке в ProjectVersion указан Unity 6000.6.9f1. Для работы с Editor использовать [инструкции проекта](../../AGENTS.md) и [локальную процедуру Unity CLI/Pipeline](../DEVELOPMENT.md). Основной игровой прогон — на RU, изменившиеся тексты и границы UI проверяются также на EN.

| Работа | От чего отталкиваться |
|---|---|
| Windows и продолжение | [Отчёт I-230](../sessions/2026-11-28-i230-chapter-evidence.md) и [сценарий главы](../../AgentScripts/Verification/VerifyChapterEvidence.cs) фиксируют прежний маршрут в Editor. Подготовка сценария использует UnityEditor. [Проверка прежнего Player](../../AgentScripts/Verification/VerifySearchPlayer.cs) показывает способ запуска игровой проверки. Сохранять прежние сборки и пользовательский слот. |
| Разговор и сюжет | В [обработчике встречи](../../Assets/TrashHunter/Runtime/World/SettlementSession.cs) темы вызываются отдельными клавишами. [Журнал квестов](../../Assets/TrashHunter/Runtime/Run/QuestJournal.cs) уже ведёт РП-07, [состояние прохождения](../../Assets/TrashHunter/Runtime/Run/GameState.cs) хранит сюжетные факты. Требуемое поведение улик, ремонта и записи задано в [STORY](../design/STORY.md). |
| Предметы и умения | [Верстак](../../Assets/TrashHunter/Runtime/World/Workbench.cs) уже показывает модели ламп. [Приёмка I-210](../sessions/2026-11-28-i210-workbench.md) фиксирует цену и результат прежних операций. Распознавание тира уже отображается при [осмотре](../../Assets/TrashHunter/Runtime/Search/SearchSession.cs). Условия обучения сверять с [правилами прогрессии](../design/PROGRESSION_AND_ECONOMY.md#навыки-и-доступная-добыча). |
| Совместимость | Исходный [формат автослота](../../Assets/TrashHunter/Runtime/Run/RunSnapshot.cs) — 6. [Загрузчик](../../Assets/TrashHunter/Runtime/Run/SaveSlot.cs) содержит переходы из прежних форматов. Проверять изменённые операции на тех же экземплярах, включая отмену, отказ записи и продолжение. |

Владелец 28 ноября поручил подготовить эстафету по [декабрьскому плану](../PLAN_2026_12.md). Его пожелания и ранее принятые правила собраны в [реестре решений](../DECISIONS.md). Два разработчика и 29 человеко-дней — основания оценки. Варианты сокращения объёма в плане остаются предложениями.

Для I-240 открытых продуктовых вопросов нет. Для последующих этапов форма редактора (I-310), жесты инструментов (I-370/I-400), условие обучения (I-420) и цена ремонта кассетника (I-440) остаются рабочими вариантами. Перед зависимым этапом сверить дизайн и новые решения владельца. Существенный выбор, который всё ещё открыт, вынести в передачу соответствующего этапа.
