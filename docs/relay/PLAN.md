# Эстафета декабря 2026

Цель — пройти декабрьский план от исходной проверки первой главы до локальной Windows-сборки с диалогами, журналом, ручной обработкой находок, обучением и продолжением истории кассетника. Отдельный результат для автора — добавить сюжетный шаг через данные и проверить его в игре. Итоговые маршруты игрока и автора описаны в [плане месяца](../PLAN_2026_12.md#как-принимаем-результат-месяца).

## Очередь

Каждая строка [декабрьского бэклога](../BACKLOG.md#декабрь-2026) — один этап на один чат. В этой таблице ведутся ID, зависимости, критерии и статусы `todo / in_progress / done / blocked`. Идём по порядку строк. На момент подготовки все 24 этапа имеют статус `todo`, предшествующий I-230 завершён.

| Этапы | Результат группы |
|---|---|
| I-240–I-290 | Исходный маршрут в Windows. В одной встрече со старьёвщиком доступны поручение, предъявление РП-07 и вопрос о метке. |
| I-300–I-350 | Автор редактирует условия и переходы главы, игрок видит поручение, сюжетную цель и известные улики. |
| I-360–I-410 | Загрязнение появляется в контейнере. Ручная мойка и замена крепления меняют конкретный экземпляр, его вид и предложение торговца. |
| I-420–I-470 | Умение открывает сведения при осмотре. После ремонта игрок изучает запись кассетника. Заключительная приёмка охватывает Editor и продолжение в новом процессе Player. |

Календарь задаёт ориентиры. Работа идёт по одному этапу за чат. Если владелец меняет объём, записать его решение и поправить затронутые зависимости, включая I-460. Для паузы передавать тот же незавершённый ID с конкретным остатком. После I-470 передать результат владельцу для закрытия.

## Начало и передача

Первый этап — I-240. Актуальный следующий ID и первое действие читать в [HANDOFF](HANDOFF.md). По завершении этапа обновить статус и ссылку на доказательства в бэклоге, состояние проекта, задание следующей сессии и передачу. Устойчивые решения сохранять в [CONTEXT](CONTEXT.md) и соответствующем постоянном документе. Учёт временных файлов — в [FILES](FILES.md).
