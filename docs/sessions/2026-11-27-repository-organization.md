# Уборка проекта, 27 ноября 2026

Игровой код разложен по подсистемам, контент поиска по типам ассетов.
Инструменты вне `Assets` сгруппированы по назначению. Команды в документах
и ссылки между скриптами обновлены. Сцена проверки установки перенесена
в `Assets/Diagnostics/`, общий файл Input Actions в `Assets/Settings/Input/`.
[Карта папок и сцен](../DEVELOPMENT.md#структура-проекта).

Иерархия `ContainerSearch` сокращена с 42 до семи корней. Окружение, свет,
точки взаимодействия, предметы и маркеры старых укладок получили свои группы.
`Search Scope` и `EventSystem` остались корневыми компонентами для загрузки.
Пустая `Startup` и компактная `Home` сохранены в существующем виде.

## Проверки

- Unity Editor 6000.6.9f1 переместил 37 ассетов и папок через
  `AssetDatabase.MoveAsset`. Проверены все 85 существовавших GUID, включая
  51 перенос с учётом содержимого папки текстур. Сохранены данные
  перемещённых файлов, зависимости поиска и список сцен для сборки.
- В Editor сравнены мировые трансформации прежних корневых объектов.
  В сохранённой сцене проверен 931 существующий идентификатор и значения
  полей. Unity пересериализовала порядок полей предметов и явно записала
  два значения области поиска, ранее подразумевавшиеся по умолчанию.
- Регрессии Editor использовали изолированные копии слотов. Копии удалены
  при закрытии эстафеты локаций и квестов.
  Обычный маршрут прошёл 16 проверок, холодный старт дома и на вылазке
  прошёл 7 и 6, новая игра 4, прыжок и наведение 30. Сценарий отказов
  прошёл 24 проверки при повторе с новой копией слота. В первом прогоне
  ожидание F5 истекло. Повтор прошёл F5, отказ записи и повтор загрузки
  подтверждённой зоны. Всего в успешных прогонах 87 проверок.
- Четыре сценария авторинга с обновлёнными путями компилируются через
  `script run --dry-run`. Перенесённая сцена `SetupCheck` прошла
  `SetupCheck.Verify`. Компиляция проекта завершилась без ошибок.
  В консоли за сессию одно предупреждение пакета Visual Studio о порте 56042,
  ранее отмеченное в I-150. В конце открыт сохранённый `ContainerSearch`
  в Edit Mode.
- Проверена 661 локальная ссылка в 61 Markdown-файле и пути команд
  к скриптам и фикстурам. Ранее изменённый `ProjectSettings.asset`
  совпадает с исходным локальным файлом по SHA-256.
  Git отмечает пробелы после пустых полей в десяти новых метафайлах
  Unity. Остальные проверки пробельных символов прошли.

Применены руководства `unity-cli`, `unity-pipeline`,
`common-workflows.md`, `playmode-verification-loop.md` и разделы Pipeline
`commands/scenes.md`, `commands/assets-and-files.md`, `commands/scripts.md`.

Ручной прогон и Windows Player в этой сессии не проверялись. Для ручного
прогона открыть `ContainerSearch`, начать Play, принять продолжение при
его появлении. У выхода нажать E и Enter. Должен открыться домашний экран.
По E на домашнем экране должна начаться следующая вылазка, а F5 должен
восстановить её без смены номера.
[Регрессия переходов](../DEVELOPMENT.md#проверка-координатора-сцен).
