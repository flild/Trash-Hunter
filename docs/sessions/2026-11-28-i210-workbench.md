# I-210 · Обработка находок в убежище

28 ноября 2026 года. Unity 6000.6.9f1, ветка `main`, исходная ревизия `b3ec91e`. Следующий этап — I-220.

## Игровой результат

В убежище ↑ и ↓ выбирают находку. B или щелчок ЛКМ по верстаку кладёт выбранную лампу или РП-07 на стол. W смывает грязь, D проверяет простое состояние, R заменяет крепление лампы после диагноза. Esc возвращает предмет в запас. Отдельные строки в запасе показывают грязный корпус, треснувший шарнир или заменённое крепление.

В рабочем примере грязная исправная SV-04 стоит 34 ₽ и после мойки 42 ₽. При мойке возвращается цвет корпуса, а подтверждённая исправность сохраняется. Проверка второй SV-04 подтверждает, что шарнир не держит плафон. Для ремонта используется одна ровная металлическая рейка из запаса. После ремонта модель показывает целое крепление, а старьёвщик предлагает 42 ₽ вместо 18 ₽. РП-07 можно осмотреть на столе. Для диагностики потребуется мастер.

Верстак в [Home](../../Assets/TrashHunter/Scenes/Home.unity) использует существующие модели из поиска. [Workbench](../../Assets/TrashHunter/Runtime/World/Workbench.cs) переключает их представление по состоянию. [ItemInspectionView](../../Assets/TrashHunter/Runtime/Ui/ItemInspectionView.cs) показывает видимый признак и результат проверки. Состояние записывается в формате 4 на паре `expedition` и `key`. [GameState](../../Assets/TrashHunter/Runtime/Run/GameState.cs) публикует ремонт вместе с расходом детали. [TradeCounter](../../Assets/TrashHunter/Runtime/Run/TradeCounter.cs) сверяет предложение с текущей записью при продаже.

## Свежие проверки

[Маршрут I-210](../../AgentScripts/Verification/VerifyWorkbench.cs) прошёл 42 проверки на RU и 42 на EN в Unity Editor при Game View 932×524. На каждой локали использована отдельная копия формата 3 с исправной лампой в сумке и запасом от других вылазок.

- Подтверждён возврат через выход из вылазки. Грязь и уценку получает только доставленная SV-04. Старая чистая SV-04 сохраняет исходную цену.
- Проверены щелчок по верстаку, подсказки и границы текста. После мойки материал возвращается к исходному цвету. Диагноз сохраняется, повторная мойка оставляет сохранение прежним.
- Ремонт требует диагностики и ровной рейки. Заблокированный `slot.pending` сохраняет прежний экземпляр, деталь, модель и цену. Повтор после разблокировки расходует рейку один раз. Вторая треснувшая лампа сохраняет состояние и отклоняет ремонт без детали. РП-07 показывает подсказку о мастере.
- Отдельный Play Mode восстанавливает обработанные вещи и их текущий вид. Старьёвщик показывает новую цену и подтверждённое состояние. Продажи начисляют 84 ₽ суммарно и удаляют ровно выбранные экземпляры.

Свежая [регрессия журнала](../../AgentScripts/Verification/VerifyQuestJournal.cs) прошла 18 проверок. Проверены форматы 1 и 2, переход на формат 4, шаги, контакты и результаты сделок. Компиляция прошла. В консоли Unity после проверки 0 ошибок и 0 предупреждений. Возвращены Edit Mode, исходные переменные автослота и локали, штатный режим работы в фоне.

На кадрах до и после мойки различались материалы корпуса. Две строки осмотра получили дополнительное место после замера границ. Использованы существующие Canvas и uGUI. Сверены страницы `UIBasicLayout.md`, `HOWTO-UIMultiResolution.md`, `script-CanvasScaler.md` и документация Pipeline по `script run` и `capture`.

Проверены совпадение 171 ключа RU/EN и пути ссылок в изменённых документах. Проверка diff прошла с учётом концевых пробелов в пустых полях Home, которые записал сериализатор Unity.

Отдельный Windows Player и ручной прогон владельца остаются непроверенными. Предыдущие сборки относятся к прежним этапам.

### Повторение

В Edit Mode открыть ContainerSearch. Подготовка создаёт копию автослота, задаёт локаль и запоминает исходные переменные для восстановления.

```powershell
$pipeline = @('--caller','plugin','--skill','unity-pipeline','--project-path','F:\UnityProjects\Trash-Hunter','--format','json')
$testPath = 'AgentScripts/Verification/VerifyWorkbench.cs'
unity command script run @pipeline -- --file $testPath --entry VerifyWorkbench.Prepare --args '[\"ru\"]'
```

Запустить Play Mode. Последовательно вызвать `VerifyWorkbench.Run` с `--args '[\"begin\"]'`, `'[\"wash\"]'`, `'[\"repair\"]'`. Затем перезапустить Play Mode на том же автослоте и выполнить последний шаг.

```powershell
unity command script run @pipeline -- --file $testPath --entry VerifyWorkbench.Run --args '[\"resume\"]' --timeout 30
```

Для EN повторить подготовку с `'[\"en\"]'`. После остановки Play Mode вызвать `VerifyWorkbench.Restore`. Для ручной проверки привезти грязную SV-04, отдельно взять треснувшую SV-04 и ровную рейку. Выбрать лампы в запасе, открыть верстак, провести доступные работы и поехать к старьёвщику. После продолжения он должен предлагать 42 ₽ за каждую обработанную лампу.
