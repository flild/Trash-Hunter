# 25 ноября 2026 — закрытие эстафеты прототипа

По команде владельца закрыта эстафета I-010–I-040. В [очереди](../BACKLOG.md#эстафета-прототипа)
все четыре этапа имеют статус `done`. [Отчёт I-040](2026-11-25-i040-windows-playtest.md)
содержит исторические результаты Editor, Windows Development и двух
запусков Release. Плейтест с людьми остаётся открытым, участников 0.
Пороги C-111 ждут согласования по [замерам I-030](2026-11-25-i030-expedition-save.md#замеры-для-c-111).
I-050 требует отдельного решения владельца.

## Итоговая сборка

`Builds/I-040/TrashHunterPrototype.exe` — Windows x64 Release из сборки
`build_5eb3039318d3` на Unity 6000.6.9f1. Запускать из `Builds/I-040/`
вместе с каталогом данных, библиотеками и `THIRD_PARTY_NOTICES.md`.
Сборка хранится локально. SHA-256 исполняемого файла:
`64c123d06925c94979acc4c1a2500d8448b78fce47c290600ba8217c9785e9a7`.

При закрытии сверены заголовок Windows x64, наличие и размеры всех 185
файлов Player из отчёта Unity, а также совпадение уведомления о лицензии
с [копией в документации](../THIRD_PARTY_NOTICES.md). Сборку не повторяли,
игровой маршрут проверен на I-040. Для ручной проверки открыть итоговый
exe в папке сборки и пройти [маршрут I-040](2026-11-25-i040-windows-playtest.md#управление-и-ожидаемый-результат).
После продажи и новой вылазки ожидается другая укладка, а после обычного
выхода и повторного запуска — продолжение с сохранённого состояния.

проверочные сборки и служебная резервная папка Unity рядом с итоговым Player.

архив. Проверены 496 локальных ссылок, включая 145 ссылок на заголовки.

включая уведомление о лицензии. Игровой код, сцены и скрипты проверки
