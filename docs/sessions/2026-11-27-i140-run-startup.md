# 27 ноября 2026 — I-140, загрузка прохождения

[RunBootstrap](../../Assets/TrashHunter/Runtime/World/RunBootstrap.cs) создаёт
область приложения и область прохождения VContainer до Awake первой сцены.
[GameState](../../Assets/TrashHunter/Runtime/Run/GameState.cs) читает слот с
самостоятельным [каталогом из 28 записей](../../Assets/TrashHunter/Resources/LootCatalog.json).
Каталог перенесён из полей существующих предметов через Unity Editor.
Записи включают прежние ID, размеры сетки, цены, состояние и состав упаковок.
Поля прежнего авторинга сохранены для исторических инструментов Editor.
В игре представления используют общий каталог по ID.

В формате 1 `atHome = true` выбирает `Home`, иначе выбирается `Search`.
Пустой слот выбирает `Search`. `SearchSession` создаёт первую укладку
при подключении к пустому прохождению. При продолжении применяются позы
из снимка. Каждый новый сценовый scope получает тот же GameState.
Физический генератор создаётся в ContainerSearch по мере необходимости.
Выбор игровой сцены по зоне относится к I-150.

## Свежие проверки

Unity 6000.6.9f1. Каждый холодный старт проведён отдельным входом
в Play Mode в пустой сцене с нулём корневых объектов. Слот читался
до подключения ContainerSearch. После остановки каждого прогона
файл аренды успешно открывался эксклюзивно.

| Слот | Результат |
|---|---|
| I-120, дома | 16 проверок. Зона Home, рейка `strip-b` в запасе, 26 ₽ после продажи радиоприёмника. |
| I-120, на вылазке | 16 проверок. Зона Search, 27 ID и их позы, открытая коробка, адаптер в руке, две вещи в сетке, поворот рейки сохранён. |
| I-040, на вылазке | 16 проверок. Зона Search, 24 исходных ID и позы. Слот записал сохранённый I-040 Windows Player при штатном закрытии. |
| Пустой каталог | 7 проверок. До входа в поиск снимок отсутствует. При входе создаётся навал, игрок начинает у первой сумки, E подбирает её и записывает слот. |

Два слота I-120 записаны кодом исходной ревизии на копии
[тестового слота I-120](../../AgentScripts/Fixtures/i120-search-acceptance.json).
Во всех трёх прежних слотах совпали идентификатор прохождения, ревизия,
поза игрока и остальные данные. Чтение и подключение сцены оставили
файлы побайтно прежними.

На прямом старте ContainerSearch [VerifyLootPackages.cs](../../AgentScripts/Verification/VerifyLootPackages.cs)
прошёл 37 проверок новой игры, 39 проверок продолжения и 5 проверок
старой вылазки с отправлением в новую. Проверены раскрытие упаковок,
ошибки записи при открытии и извлечении, восстановление содержимого и
сетки, расположение вещей после возврата и цены предложений.

Проверки запущены через `unity command script eval` с полным путём к проекту.
[Команда и подготовка холодного старта](../DEVELOPMENT.md#проверка-запуска-прохождения).
Итоговый `script recompile_status` завершился успешно, `console status`
показал 0 ошибок и предупреждений. Подробные результаты и изолированные
слоты находятся в `Logs/I-140/`. Play Mode остановлен. Исходная сцена,
переменные среды и настройки Editor восстановлены.
