# I-170 — система квестов

Ветка main, исходный коммит `38de9a2`, исходное рабочее дерево чистое.
Реализован [контракт квестов](../ARCHITECTURE.md#квесты-i-170).
В автослоте 3 вместе сохраняются экземпляр, шаг, контакт и касса.
Осмотр передаёт факт из SearchSession. Предъявление, сдача и продажа
используют TradeCounter. Оба [проверочных определения](../../AgentScripts/Fixtures/i170-quests.json)
исполняет один QuestJournal.

## Свежие проверки

Unity 6000.6.9f1, Pipeline 1.0.0. Перекомпиляция завершилась успешно.
Команды запускались с `--project-path F:\UnityProjects\Trash-Hunter --caller plugin --skill unity-pipeline`.

| Режим | Команда Pipeline и результат |
|---|---|
| Edit Mode | `script eval -- --file AgentScripts/Verification/VerifyQuestJournal.cs --timeout 30`. 18 проверок. Состояние загружается посреди шага и после завершения. Предъявление сохраняет вещь и открывает контакт, передача списывает ровно один экземпляр и начисляет награду один раз. Неподходящий экземпляр и повтор отклоняются. Блокировка slot.pending проверена для осмотра, предъявления, продажи и передачи. При отказе состояние и байты основного файла сохраняются. |
| Play Mode | `script eval -- --file AgentScripts/Verification/VerifySceneTransitions.cs --timeout 50`, фаза `route`, 29 проверок. Копия поискового слота I-160 формата 2 с упакованным `radio-a` и экземпляром той же модели в запасе. F5 записал формат 3. Виртуальный ввод прошёл путь поиск → дом → старьёвщик → дом → новая вылазка. Продажа списала выбранный экземпляр один раз. |

Первый запуск маршрута остановился на предусловии пустой сумки тестовой
копии. Для итогового прогона в копию положили радио и пересчитали контрольную
сумму. Локальные слоты и подробный результат удалены при [закрытии эстафеты](2026-11-27-world-relay-closure.md).
После проверки восстановлены исходная сцена, Edit Mode, переменные среды
Unity и настройка фонового выполнения.

Команда осмотра проверена напрямую в Edit Mode. Игровой ввод с активным
поручением проверяется в I-180, прогон Windows Player входит в I-190.
